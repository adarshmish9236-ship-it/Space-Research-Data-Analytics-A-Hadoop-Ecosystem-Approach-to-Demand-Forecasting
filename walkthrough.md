# ORBITALYTICS: Big Data Intelligence for Space Research

Welcome to the complete deployment of ORBITALYTICS! The platform is now fully functional, bridging advanced Big Data processing with a state-of-the-art interactive front end.

## 🚀 System Architecture Deployed

The platform follows a true end-to-end Big Data workflow:
1. **Data Lake**: Synthetic space research data representing historical missions, satellites, and launches.
2. **Apache Spark ETL**: Data is ingested, cleaned, joined, and aggregated using PySpark.
3. **Storage Engine**: Cleaned data is written as columnar Parquet files (surrogate for HDFS).
4. **Machine Learning**: Spark MLlib executes time-series forecasting, utilizing feature engineering and a Gradient Boosted Trees model.
5. **Serving Layer**: A FastAPI backend exposes the Parquet analytics via high-performance REST endpoints.
6. **Presentation Layer**: A dark-mode, futuristic React + Vite frontend visualizes the analytics.

## 📊 Feature Walkthrough

### 1. Mission Control Overview
The dashboard provides a macroscopic view of global space operations. It integrates KPIs for total missions and success rates, and plots a historical demand curve via a smooth area chart. A pie chart highlights market share across nations.

### 2. Demand Forecast (ML Powered)
This section leverages the ML predictions generated by the Spark pipeline. It presents both historical data and future predictions (next 3 years) bounded by confidence intervals (RMSE). Interactive dropdowns allow you to filter predictions by country and mission type.

### 3. Space Intelligence Center
Dive into the algorithm diagnostics. This module visualizes the accuracy, error margins (MAPE, RMSE), and computational speed of the evaluated models (Linear Regression, Random Forest, GBT) via a responsive Radar Chart.

### 4. Scenario Lab
Engage in "What-if" simulations. Adjust parameters like *Satellite Growth* and *Launch Capacity* via sliders, and trigger distributed ML inference to see how these factors could exponentially influence mission demand.

### 5. Data Explorer
Direct tabular access to the processed HDFS/Parquet files. You can sift through raw mission logs, satellite details, and the aggregated demand analytics in a high-performance grid.

### 6. System Monitor
Real-time observation of the Big Data cluster. Watch component health states, simulated CPU/Memory diagnostics, and the operational status of the Spark ETL engine and FastAPI server.
